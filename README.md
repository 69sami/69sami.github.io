# Samiullah Panwar — Academic Portfolio

A free, responsive academic website using only HTML, CSS, and JavaScript. On desktop the profile stays fixed on the left, while the main page scrolls on the right.

## Publish on GitHub Pages for free
1. Create a GitHub account if necessary.
2. Create a **public** repository named `69sami.github.io` (replace 69sami with your real GitHub username).
3. Upload `index.html`, `styles.css`, `script.js` and the **assets** folder to the **root** of your repository. Do not upload the enclosing `samiullah-academic-portfolio` folder as an extra directory.
4. Open repository **Settings → Pages** and select **Deploy from a branch → main → / (root)**, then save.
5. The website will be published at `https://69sami.github.io/` after GitHub's deployment completes.

If using a differently named repository, the default address is `https://69sami.github.io/REPOSITORY/` and the relative paths in this project still work.

## Update it
- **Photo:** your portrait is already included at `assets/profile.png`. Replace this file to update it.
- **CV:** replace `assets/Samiullah_Panwar_CV.pdf` with your updated CV under the same name.
- **Biography, sections, awards:** edit the corresponding text in `index.html`.
- **Colors, layout:** edit CSS variables at top of `styles.css`.
- **Add publications:** create a publication section when you have actual publications; do not label ongoing research as published.

## Before going public
- Confirm all CV facts and quantified claims with your latest records.
- Your email address appears publicly. The mobile phone number has been redacted from the included public CV; keep your original CV private if you prefer.
- The profile uses your uploaded portrait.
- The solar project visual is illustrative. The stability project now includes your supplied model/simulation result images; please verify figures and research claims before sharing.

## After graduation
When the B.E. degree is officially awarded, update the introduction and education timeline from “completing” and “anticipated” to confirmed completion. This prevents an admissions reviewer mistaking an expected degree for an awarded one.
