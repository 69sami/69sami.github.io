Put your files in this folder:

- resume.pdf        -> your resume/CV (referenced in data.js as resumeFile)
- project1.jpg etc.  -> any project images (reference them in data.js, e.g. image: "assets/project1.jpg")
- photo.jpg          -> your profile photo, if you want to add one later

Keep file names simple: lowercase, no spaces (use hyphens or underscores instead).
